# SD-LoRa

**Телеграм бот**  
Проект представляет собой Telegram-бота, написанного на JavaScript.

## О проекте
Репозиторий содержит исходный код Telegram-бота. Бот создавался для работы с изображениями через Stable Diffusion (SD) или для взаимодействия с LoRa-моделями.

## Технологии
- **JavaScript** — язык программирования.
- **Node.js** — среда выполнения.
- **Telegram Bot API** — взаимодействие с мессенджером (предположительно).
